# PrimeEstate

**PrimeEstate** is a modern, responsive real estate web application built with HTML, CSS, and JavaScript. It is designed to showcase available land properties in a visually appealing layout, offering users an intuitive and engaging experience. The platform features interactive property cards, a map for spatial context, and supporting sections such as About, Features, Testimonials, and Contact.

---

## Project Overview and Description

The goal of PrimeEstate is to present land/property listings with elegant design and user-friendly navigation. The application includes:

- A hero section for branding
- Animated property listings (`land1.jpg` to `land9.jpg`)
- Interactive modals for more information
- Customer testimonials
- Contact section with form
- Responsive design for all devices

It is ideal for educational, demo, or front-end portfolio purposes related to real estate UI/UX.

## Setup Instructions

To run PrimeEstate locally, follow these steps:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/sandaru-sdm/PrimeEstate.git
   cd PrimeEstate
   ```

2. Run the app:

* Open index.html directly in a browser
* Alternatively, use a live server (e.g., VS Code Live Server extension)

> No additional dependencies or build steps are required.

--- 
## Usage Guidelines
Once the page is loaded:

* Scroll through each section (Hero, About, Features, Properties, Testimonials, Contact)
* Hover over property cards to trigger animations
* Click on property items to view modal interactions (controlled via `script.js`)
* Contact form and footer are static but styled for realism

#### Images and media are located in the `assets/` folder, and the application is fully responsive.
